# docs

Documentación técnica y de producto de Bifrost.

- `VISION.md`: qué es el proyecto, para quién y qué queda fuera.
- `DECISIONS.md`: decisiones tomadas y reglas fijas del proyecto.
- `ARQUITECTURA.md`: stack, esquema SQLite, criptografía, contratos API e instalación.
- `PROTOCOLO-NODOS.md`: túnel `HTTP CONNECT`, autenticación, heartbeat y rotación de tokens.
- `HISTORIAS.md`: historias de usuario (`HU-01` a `HU-26`) con criterios de aceptación comprobables.
- `ORDEN-DE-IMPLEMENTACION.md`: fases secuenciales y dependencias por historia.
- `PENDIENTES.md`: ítems aún abiertos o en verificación.
- `PISTAS.md`: pruebas de endpoints y notas técnicas verificadas.

Cualquier decisión nueva va primero a `DECISIONS.md`, antes de escribir código.
